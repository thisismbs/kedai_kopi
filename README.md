1. Pemilihan Flexbox dan Grid
Flexbox saya gunakan di navbar karena susunannya bersifat satu dimensi (satu baris) sehingga mudah disejajarkan. Sedangkan Grid saya gunakan di halaman menu karena card menu memerlukan tata letak dua dimensi (mengatur baris dan kolom sekaligus) agar jumlah kolomnya bisa disesuaikan tergantung menggunakan device apa.
